# Editing Checklist

## Pass 1: Structure (Big Picture)

- [ ] Does the opening hook the reader?
- [ ] Is there a clear thesis or central point?
- [ ] Does the piece flow logically from one idea to the next?
- [ ] Are sections in the right order?
- [ ] Does every section serve the main point?
- [ ] Is anything missing? Anything redundant?
- [ ] Does the ending land?

## Pass 2: Content (Ideas)

- [ ] Are claims supported with evidence or examples?
- [ ] Is anything unclear or ambiguous?
- [ ] Are there gaps in logic or missing transitions?
- [ ] Is the level of detail appropriate for the audience?
- [ ] Are examples concrete and relevant?
- [ ] Is the tone consistent throughout?

## Pass 3: Line Editing (Sentences)

- [ ] Are sentences clear on first read?
- [ ] Is there unnecessary repetition?
- [ ] Are verbs strong? (Replace "was running" → "sprinted")
- [ ] Any unnecessary words? ("In order to" → "To"; "Due to the fact that" → "Because")
- [ ] Does sentence length vary?
- [ ] Does it sound natural read aloud?
- [ ] Are transitions between paragraphs smooth?

## Pass 4: Copy Editing (Polish)

- [ ] Spelling correct?
- [ ] Grammar correct?
- [ ] Punctuation consistent?
- [ ] Formatting consistent (headers, lists, spacing)?
- [ ] Names, dates, and facts verified?
- [ ] Links working?
- [ ] Final read-aloud check?

## Quick-Check: Common Issues

| Issue | Fix |
|-------|-----|
| Passive voice | Find "was/were [verb]ed" → rewrite as active |
| Weak openers | Delete "There is/are" and "It is" sentence starts |
| Filler words | Cut "really," "very," "just," "quite," "somewhat" |
| Nominalizations | "Make a decision" → "Decide"; "Conduct an investigation" → "Investigate" |
| Hedging pile-up | One hedge is fine; three in a sentence is weak |
| Run-on sentences | If you need a breath reading it aloud, add a period |
| Buried lede | Check if paragraph 3+ has your real opening |
